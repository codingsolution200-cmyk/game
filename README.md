# 🎮 SapSidi - Snake & Ladder Game (Kotlin)

SapSidi is a modern and interactive Snake & Ladder Android game built using Kotlin.  
It provides smooth gameplay, beautiful UI design, and multiple play modes for an engaging experience.

---

## ✨ Features

- 🎲 Classic Snake & Ladder Gameplay  
- 🤖 Play vs Computer (AI Mode)  
- 👥 Local Multiplayer Mode  
- 🎨 Attractive UI with smooth animations  
- 🔄 Play Again & Main Menu Options  
- ⚙️ Settings Option  
- 📊 Score Tracking System  
- 📢 Ad Integration (Banner Ads ,Interstitial Ads)

## 🎯 How to Play

- Roll the dice 🎲  
- Move your token forward  
- Climb ladders to go up ⬆️  
- Avoid snakes (you will go down) ⬇️  
- Reach 100 first to win 🏆
